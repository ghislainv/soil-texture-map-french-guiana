# soil-texture-map-french-guiana

This repository includes the code and data used to produce the results of the following scientific article:

**Khan S., G. Vieilledent, I. Maréchaux, S. Guitet, O. Brunaux, F. Soulard, C. Stahl, C. Baraloto, C. Fortunel, and V. Freycon.** Soil texture variation within a tropical region is predominantly driven by geomorphology and geology, and not captured by global soil maps.
